## Описание
Отчеты лабораторных работы по предмету **Математическое моделирование**. 

## Содержание

| Лабораторная работа | Описание                                                       |
| ------------------- | -------------------------------------------------------------- |
| `lab_1.pdf`         | Построение модели теплопередачи с терморегулятором и без него. |
| `lab_2.pdf`         | Исследование популяционной модели Лотки-Вольтеры.              |
| `lab_3.pdf`         | Модель математического маятника.                               |
| `lab_4.pdf`         | Моделирование движения тела во вращающейся системе координат.  |
| `lab_5.pdf`         | Численные методы решения одномерного уравнения переноса.       |


## Стек

- Язык программирования: Python 3.12
- Используемые библиотеки: Numpy, Matplotlib
